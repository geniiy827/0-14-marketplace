# mcanim 2.0 — 3D-мультики в стиле Майнкрафт по текстовому сценарию

Пишешь сценарий обычным текстом → получаешь 3D-видео 720p: озвучка, липсинк, моргание, субтитры,
музыка на нотных блоках, игровые звуки, мобы, частицы и авто-камера.
Текстуры блоков, модели мобов, звуки и скин-паки взяты из клиента 0.14 (папка assets/).

## Запуск
    python3 mcanim.py сценарий.txt                 # полный рендер (≈5 с работы на 1 с видео)
    python3 mcanim.py сценарий.txt --plan          # раскадровка без рендера
    python3 mcanim.py сценарий.txt --stills 3,12.5 # контрольные кадры PNG
    python3 mcanim.py сценарий.txt --preview       # быстрый черновик 360p
Неизменённые сцены берутся из кэша: правка одной сцены перерендеривает только её.
Нужно: Python 3, numpy, Pillow, moderngl (+ EGL/Mesa), ffmpeg, RHVoice с русскими голосами.

## Шапка
    название: ...   подзаголовок: ...   конец: Продолжение следует...
    мир: равнина          # равнина | лес | пустыня | зима
    время: день           # день | закат | ночь
    настроение: весело    # весело | спокойно | погоня | тревожно | ночь | эпично | грустно
    актёр Квас: скин=kvas.png голос=artemiy скорость=110 место=3,0 поворот=90 цвет=#ff8a3a
    актёр Зина: скин=zina.png голос=irina скрыт=да        # появится позже
    актёр Нартер: ... лежит=да                             # спит в начале (Zzz)
    моб Бурёнка: тип=корова место=6,-3                     # корова | свинья | курица | овца | волк

## Сцены
    == Название | мир=лес время=закат настроение=погоня
    Квас: Привет! [машет] Как дела?          # [действие] срабатывает в этом месте фразы
    Нартер: [Квас прыгает] Опять?            # в скобках можно указать другого персонажа
    Бурёнка: Мууу.                           # моб «говорит» своим игровым звуком
    * Квас бежит к Нартеру ; Нартер машет    # через «;» — одновременно
    * Нартер стоит -2,1 90                   # поставить без анимации (90 = поворот в градусах)
    * Гений появляется 3,-2                  # с облачком и звуком;  «исчезает» — наоборот
    * Света скрыта                           # тихо убрать из кадра
    * Зина держит банку ; Зина убирает       # предмет в руке
    * звук взрыв                             # взрыв, дверь, отрыжка, уровень, ой, удар, му, хрю, гав, ведьма, крипер, гром…
    * пауза 1.5
    * камера крупно Квас / * камера авто     # общий, двое, крупно, сплеча, средний, облёт, сверху, следом

## Действия
идёт/бежит к X, прыгает, машет, кивает, мотает, смотрит на X, поворачивается к X, показывает на X,
садится, встаёт, падает, спит, танцует, смеётся, удивлён, радуется, бьёт X (звёздочки), фейспалм,
пожимает плечами, думает, боится (капли пота), злится, приседает, оглядывается, плачет, кланяется,
хлопает, плюёт в X (плевок долетает и висит на лице), тужится, хватает X, влюбляется (сердечки),
ест, прячется, зевает, хвастается. Число после действия — длительность в секундах.

Цели: имя в любом падеже («к Квасу», «в Зину»), точка `5,-3`, метки `дом`, `пруд`, `центр`, `лес`, `камера`.
Предметы: банка, ведро, яблоко, хлеб, торт, рыба, книга, кость, палка, меч, лопата, топор, кирка, удочка,
морковь, цветок, алмаз, золото, яйцо, печенье, арбуз, компас, карта, пирог, лук, зелье, мясо, часы, ножницы.
Голоса: aleksandr-hq, artemiy, mikhail, pavel, yuriy, vitaliy (м); anna, irina, elena, tatiana, victoria, arina (ж).
Скин-паки игры лежат в assets/skinpacks (TownFolk, CityFolk, StoryMode, Festive, Halloween и др.).
