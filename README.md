# mcanim 3.0 — конструктор 3D-мультиков в стиле Майнкрафт

Сценарий — обычный текст. Всё новое (локации, действия, позы, эффекты, объекты, камера) описывается
в тексте сценария или в `library/*.txt`. Код движка трогать не нужно.

## Команды
    python3 mcanim.py сценарий.txt --check         # автопроверка без рендера (секунды): говорящий в кадре,
                                                   #   камера/персонажи в блоках, персонажи друг в друге
    python3 mcanim.py сценарий.txt --plan          # раскадровка
    python3 mcanim.py сценарий.txt --stills 3,12.5 # контрольные кадры PNG (ровно как в рендере)
    python3 mcanim.py сценарий.txt                 # локальный рендер
Облако: в `render.txt` путь к сценарию + имя файла → push в ветку `mcanim` → 16 машин параллельно →
видео в ветке `renders` (~3–4 мин на серию).

## Шапка
    название: …   подзаголовок: …   конец: Продолжение следует...
    мир: равнина            # равнина | лес | город | пустыня | зима | пусто | <своё имя>
    время: день             # день | закат | ночь
    настроение: весело      # музыка: весело спокойно погоня тревожно ночь эпично грустно
    толпа: 16 мир=город скины=../../skins/crowd центр=0,1 радиус=9   # прохожие гуляют сами, не сталкиваясь
    актёр Квас: скин=kvas.png голос=artemiy скорость=110 место=3,0 поворот=90 цвет=#ff8a3a
        # ещё: тон= размер=2 (великан) высота=1 (парит) скрыт=да лежит=да
    моб Охранник: тип=зомби место=-4,-5 поворот=0 [текстура=… размер=… высота=…]
        # корова свинья курица овца волк зомби скелет крипер эндермен паук пещерный_паук
        # житель(текстура=farmer|librarian|priest|smith|butcher) ведьма слизень голем снеговик кролик оцелот
        # летучая_мышь гаст блейз свинозомби зомби_житель визер_скелет грибная_корова чешуйница магмовый_куб
    объект Ракета: блок=тнт место=4,4            # любой материал
    объект Торт: предмет=торт размер=0.6         # предмет из игры
    объект Утка: модель=duck.glb размер=1.2      # 3D-модель .glb/.gltf/.obj (размер = высота в блоках)

## Локации из текста
    строить тюрьма: основа пусто
    строить тюрьма: пол каменный_кирпич -10,-10 10,10
    строить тюрьма: коробка каменный_кирпич -6,0,-14 6,4,-7 дверь=юг крыша=тёмные_доски имя=тюрьма
    строить тюрьма: дом доски 10,-5 ширина=7 глубина=6 высота=4 крыша=тёмные_доски
    строить тюрьма: стена железо -10,-7 -10,9 высота=2
    строить тюрьма: куб красная_шерсть 4,0,2 5,1,3     (убрать x,y,z x,y,z — очистить)
    строить тюрьма: дерево 9,9 | факел 1,0,-4 | цветы -8,5 8,8 плотность=0.2 | метка двор 3,4
    строить тюрьма: схематика замок.schem 10,0,-20 поворот=90 имя=замок   (.schematic / .schem)
    == Сцена | мир=тюрьма время=ночь настроение=тревожно
Материалы: русские имена (доски, тёмные_доски, кирпич, каменный_кирпич, кварц, обсидиан, красная_шерсть,
синяя_глина, сено, тнт, стекло…) или любая текстура из assets/blocks (`wool/11`, `quartz_block/1`).
Персонажи сами встают на построенные платформы.

## Реплики и действия
    Квас: Привет! [машет] Как дела?          # [действие] срабатывает в этом месте фразы
    Нартер: [Квас прыгает] Опять?            # можно указать другого персонажа
    Бурёнка: Мууу.                           # моб «говорит» своим игровым звуком
    * Квас бежит к Нартеру ; Нартер машет    # «;» — одновременно
    * Нартер стоит -2,1 90                   # поставить (90 = поворот) / Света скрыта / Гений появляется 3,-2
    * Квас поза скрестил руки                # держать позу до «поза нет» или «встаёт»
    * эффект конфетти Гений 2 / эффект взрыв 3,0
    * Квас бросает снежок в Нартера          # снаряд: эффект с полёт=цель
    * Ракета летит к 0,4 9 ; Ракета вращается 3   # 9 = высота полёта
    * Торт крепится к Квасу [голову|спину] / Торт отцепляется
    * Квас размер 2.5                        # великан; размер 1 — обратно
    * Зина стреляет в Кваса                  # дротик + усыпление
    * звук взрыв / * пауза 1.5
Встроенные: идёт, бежит, крадётся, прыгает, машет, кивает, мотает, смотрит, поворачивается, показывает,
садится, встаёт, падает, спит, танцует, смеётся, удивлён, радуется, бьёт, фейспалм, пожимает плечами,
думает, боится, злится, приседает, оглядывается, плачет, кланяется, хлопает, плюёт в, тужится, хватает,
влюбляется, ест, прячется, зевает, хвастается, держит/несёт <предмет>, убирает, исчезает.
Из library/действия.txt: отжимается, приседания, бьёт ногой, обнимает, держится за голову/живот, молится,
салютует, ковыряется в носу, чешет голову, показывает вверх, звонит, пьёт, селфи, дэб, флосс, марширует,
сальто, кувырок, трясётся, ползёт, машет руками, кричит, стучит, тянется, смущается, ждёт, тыкает,
подзывает, сдаётся, бросает, взрывается от злости, колдует, плавает. Позы: руки в боки, скрестил руки,
лежит на животе/спине, боевая стойка, грустит, зомби, думает поза.
Эффекты (library/эффекты.txt): слёзы деньги конфетти дым огонь искры пузыри снег дождь взрыв ноты магия
пыль румянец брызги; снаряды: бросок снежок яйцо торт.

Каналы (градусы; высота/сдвиг — блоки): голова_вверх/_поворот/_наклон, тело_вперёд/_вбок/_поворот,

## Камера
Авто-режиссёр выбирает план и перебирает до 11 ракурсов: говорящий в кадре, не закрыт блоками или
чужой спиной, камера не в стене; движение плавное, без рывков.
    * камера общий | двое | крупно Квас | сплеча Квас | средний Квас | облёт | сверху | следом Квас | авто
    * камера точка 0,3,8 смотрит Квас поле=40
    * камера путь 0,5,15 0,2.4,7.5 смотрит Квас      # проезд за время следующих действий
