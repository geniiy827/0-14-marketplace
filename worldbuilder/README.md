# World Builder 0.14.3

Редактор миров серверов **Minecraft PE 0.14.3** (ядро Genisys, формат McRegion) прямо внутри **Minecraft Java 1.20.1** (Fabric).
Мир читается и пишется в родном формате PocketMine — без конвертации в Java. Java-блоки нужны только для показа.

## Установка (по шагам)

1. Установи **Fabric Loader** для Minecraft **1.20.1** (официальный установщик с fabricmc.net, версия загрузчика 0.15.x).
2. Скачай **Fabric API** для 1.20.1 (версия 0.92.x) и положи в папку `.minecraft/mods`.
3. Положи `WorldBuilder-0.14.3-1.20.1.jar` в ту же папку `.minecraft/mods`.
4. Запусти профиль **fabric-loader-1.20.1**. В главном меню под «Сетевая игра» появится кнопка **World Builder 0.14.3**.

Советую сделать для редактора отдельный профиль/папку игры: мод регистрирует свои служебные блоки (для блоков PE, которых нет в Java).

## Первые шаги

1. Нажми **World Builder 0.14.3** → заполни FTP (адрес, порт, логин, пароль) → **Подключиться**.
   Строку вида `ftp://user:pass@host:21/path` можно вставить прямо в поле «Адрес» — она разложится по полям.
2. Мод сам зайдёт в папку `worlds/` и подсветит миры (значок ◆). Двойной клик — открыть.
3. **Перед сохранением на сервер выключи сервер в панели**, после — включи.
4. Сохранение: **Ctrl+S** / кнопка «Сохранить» → ZIP, «новый мир на сервер» или «перезаписать» (с резервной копией).

Без сервера: «С диска / ZIP» на экране подключения.

## Управление (главное)

| Действие | Клавиша |
|---|---|
| Осмотреться | зажать ПКМ над вьюпортом |
| Полёт | W/S — по взгляду, A/D — вбок, Пробел/Shift — вверх/вниз |
| Скорость | колесо при зажатой ПКМ; двойное W — ×2 |
| Наезд / орбита / панорама | колесо / СКМ / Shift+СКМ |
| Пипетка | клик СКМ (Alt — без ориентации) |
| Инструменты | V Инспектор, P Карандаш, E Ластик, K Ведро, M Выделение, B Кисть, L Линия, G Перемещение, T Рельеф, Y Биомы, U Линейка, O Объекты |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Копировать / вырезать / вставить | Ctrl+C / Ctrl+X / Ctrl+V |
| Заполнить / заменить / очистить | Ctrl+F / Ctrl+H / Delete |
| Повернуть / отразить | R / Alt+R |
| Скрыть панели, срез, справка | Tab, N, F1 |

Полный список — **F1** в редакторе. Все одиночные клавиши переназначаются в «Файл → Настройки → Клавиши».

## Что умеет

- FTP (двоичный режим), FTPS (явный TLS), SFTP (пароль или ключ, проверка ключа хоста); профили, «Запомнить меня» (пароли — AES-GCM).
- Файловый браузер сервера с автоопределением миров, кэш (повторно качаются только изменённые файлы), офлайн-режим (папка/ZIP).
- Чтение/запись McRegion и level.dat с сохранением всех тегов и их типов (проверено побайтно на твоём мире).
- Рендер моделями и текстурами Java 1.20.1: цвет травы из BiomeColors, вода, соединения заборов/панелей/стен, углы ступеней, двери, сундуки, кровати, таблички, головы, горшки.
- Карандаш с умной ориентацией, ластик, ведро, выделения (куб, сфера/эллипсоид, цилиндр, конус, пирамида, тор, полусфера, полуцилиндр, контур, волшебная палочка, кистевое, по типу, лассо), булевы операции, ручки размера и перемещения, числовые поля.
- Смеси (случайная, градиент, шум, шахматка, плитка буфера), маски, все действия раздела 18, кисти раздела 19, линии/сплайны, генератор объектов, биомы.
- Буфер с историей, вставка-призрак, поворот/отражение с перекодировкой мет, импорт `.schem` (v2/v3) и `.schematic` (Alpha/Pocket) с отчётом и заглушками, экспорт `.schematic` Pocket, библиотека заготовок.
- Отмена/повтор с вкладкой «История», свет и HeightMap при сохранении, `TerrainPopulated=1`, проверка тайлов, резервные копии, проверка конфликтов, автосохранение сессии и восстановление после вылета.
- «Файл → Создать тестовый мир всех блоков» — для сверки с клиентом 0.14.3.

## Частые вопросы

**Сервер затёр мои изменения.** Сервер был запущен и сохранил мир при выключении. Выключай сервер перед загрузкой правок.

**Сервер досыпал руды и деревья в мою постройку.** Оставь включённой галочку «Запретить серверу досыпать руды и деревья» при сохранении.

**Неправильно повёрнут блок (повторитель, наковальня, портал…).** Это блоки со статусом «проверить» (жёлтая метка в палитре). Создай тестовый мир всех блоков, сравни в 0.14.3 и поправь `wb_blocks_pe0143_java1201.json` — код менять не нужно.

**«Формат мира не поддерживается».** Нужен McRegion: в `pocketmine.yml` → `level-settings` → `default-format: mcregion`.

## Сборка из исходников

```
cd worldbuilder
gradle build        # Gradle 8.14, Java 17+
```
Готовый файл: `build/libs/WorldBuilder-0.14.3-<версия>.jar`. В репозитории сборка идёт автоматически (GitHub Actions, workflow `worldbuilder.yml`).
