# Ручная проверка (чек-лист)

## Подключение
- [ ] FTP: вход, неверный пароль → «Неверный логин или пароль», неверный адрес → «Адрес не найден».
- [ ] «Проверить подключение» показывает число элементов в папке.
- [ ] «Запомнить меня»: при следующем открытии поля заполнены; снятие галочки удаляет пароль.
- [ ] FTPS с самоподписанным сертификатом — вопрос с отпечатком; SFTP — вопрос о ключе хоста.

## Открытие мира
- [ ] Браузер заходит в `worlds/`, миры отмечены ◆, карточка показывает LevelName/генератор/спавн.
- [ ] Повторное открытие без изменений на сервере — мгновенно из кэша.
- [ ] Предупреждение «сервер может перезаписать изменения» показывается один раз.
- [ ] Трава окрашена цветом из BiomeColors, видны руды, вода.

## Камера
- [ ] WASD работает только когда курсор над вьюпортом; W с наклоном летит вверх/вниз.
- [ ] Зажатая ПКМ скрывает курсор, после отпускания курсор в той же точке.
- [ ] Колесо при ПКМ меняет скорость, двойное W ускоряет.

## Правка
- [ ] Карандаш: ступени по взгляду, перевёрнутые при клике в верхнюю половину; плита на плиту → двойная; брёвна по грани; факелы по опоре; двери и кровати из двух частей.
- [ ] Сундук получает тайл Chest (Инспектор показывает NBT).
- [ ] Выделение сферы → растянуть ручкой в эллипсоид → «Полая» → Заполнить смесью.
- [ ] Замена ступеней на ступени с сохранением ориентации.
- [ ] Копировать → вставить с поворотом R: двери, ступени, факелы смотрят правильно.
- [ ] Импорт .schem: отчёт, заглушки, «Заменить заглушки», сохранить с заглушками нельзя.
- [ ] Ctrl+Z / Ctrl+Y, вкладка «История» — клик по шагу.

## Сохранение
- [ ] ZIP: внутри папка мира с level.dat и region/*.mcr.
- [ ] Новый мир на сервер: папка создана, подсказка про server.properties.
- [ ] Перезапись: резервная копия в `.minecraft/worldbuilder/backups`, загружены только изменённые регионы.
- [ ] Конфликт: изменить мир на сервере после открытия → диалог с вариантами.
- [ ] После перезапуска сервера в 0.14.3: постройка на месте, свет правильный, сундуки открываются.
- [ ] Вылет игры → при следующем запуске «Найдена несохранённая работа».

## Тестовый мир всех блоков
- [ ] «Файл → Создать тестовый мир всех блоков» → залить на сервер → сравнить с клиентом 0.14.3.
- [ ] Расхождения поправить в `wb_blocks_pe0143_java1201.json`.

## Автоматические проверки
`gradle test` — индексы чанка, побайтная круговая проверка NBT чанков и level.dat на мире пользователя
(если положить его в `src/test/resources/worlds`), тайлы при установке/отмене, свет (факел в закрытой комнате, дыра в потолке),
4 поворота и двойное отражение для всех id:meta таблицы, генерация тестового мира.
