# NOVA client — MCPE 0.14.3 (RCodeStudio)

Исходники и инструменты клиента. Всё о проекте — в **MEMORY.md**; язык модов — `docs/MCMOD_SCRIPT.md`, `docs/MCMOD_API.md`.

```
sh tools/setup.sh     # зависимости + команда nova (нужны mcpe.apk, keys/nova.jks — их нет в репозитории)
nova build            # out/NOVA-0.14.3-<VERSION>.apk
nova                  # список команд (символы, дизасм, вызовы, vtable, расшифровка вылетов)
```
