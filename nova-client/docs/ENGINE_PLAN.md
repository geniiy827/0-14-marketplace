# NOVA Engine — свой движок на Java (план)

## Что такое MegaCraft 0.2.0 (разбор APK, 31.10.2026)
- `com.lituty.megacraftpe`, ~15 МБ. Движок — **свой C++ с нуля** на библиотеке **raylib** (графика/звук/ввод),
  `libmegacraftpe.so` 4.8 МБ (arm64) + 3.7 МБ (armv7), Java-обёртка 45 КБ. Ни строчки кода Mojang.
- Это **только сетевой клиент**: нет генератора мира, мобов, сохранений. Вся игра — на сервере, клиент рисует и шлёт ввод.
  Отсюда маленький размер и «много протоколов»: `LegacyNet::Mcpe081/Mcpe015/Mcpe113Protocol`, `RakNetSession`, `Java188`.
- Свои классы: ChunkMeshBuilder, WorldLighting, DynamicLight, ShaderMine (шейдеры: туман, небо, облака),
  AnimalRenderer/HumanoidAnimator (модели мобов), Player (физика игрока на клиенте), I18n, OnlineSession.
- В APK лежат звуки и картинки Mojang (assets/sound/*.wav, image/*) — юридический риск для магазина.
- Эффекты из трейлера — клиентская отрисовка на их сервере, моды ещё не выпущены.

## Решение пользователя: свой движок на Java/Kotlin
Язык: **Java** сейчас (javac 21 + dx уже есть, Kotlin-компилятор в эту среду не скачать — maven/релизы закрыты),
Kotlin — когда появится компилятор (совместим 1:1). Графика: **OpenGL ES 3.0 напрямую** (android.opengl, GLSurfaceView),
без libGDX (его не скачать; и тоньше слой = меньше APK). Нативного кода почти нет → один APK для arm64/armv7/x86.

### Как избежать лагов Java на телефоне
- чанки и меши в примитивных массивах / direct ByteBuffer, без объектов на блок;
- построение мешей и свет — в рабочих потоках; в кадре почти нет выделений памяти (нет сборок мусора);
- одна большая текстура-атлас, мало вызовов отрисовки (меш на секцию 16×16×16).

### Что берём из нынешнего NOVA
- **McMod Script целиком** (интерпретатор уже на Java) + все API-описания (mcmod/api/*.tsv), блоки/предметы/модели
  (разбор .bbmodel/.geo.json — Java), паки .mcres, дизайн, логотип, интро, звуки интро.
- Ресурсы игры: **из установленного у игрока Minecraft PE** (как ресурс-пак), в APK — только наше.

### Этапы (каждый — сборка на телефон)
1. **Прототип (1–2 недели):** открыть настоящий мир 0.14 (LevelDB, ключи чанков 0.14), нарисовать с текстурами
   из установленной игры, ходить/летать, ставить/ломать блоки. Проверка: FPS и плавность на телефоне.
2. **Игра:** свет (небо + блоки), вода/лава, физика игрока, инвентарь/творческий режим, звуки, интерфейс (свой UI в стиле NOVA).
3. **Мир:** генератор (как 0.14 по сиду — или свой), сохранения, мобы (ИИ, модели, анимации каждый кадр).
4. **Моды:** McMod Script + то, что было трудно в старом клиенте: эффекты (fx.*), движущиеся постройки,
   свои сущности/боссы, шейдеры, камера для роликов; позже — Java-моды (dex) «без ограничений».
5. **Сеть:** клиент для серверов 0.14 (RakNet, протокол 70), потом другие версии.

Старый NOVA (патч оригинала) остаётся рабочим клиентом, пока движок не догонит.

## Права и ресурсы (31.10.2026)
- Движок с нуля = своя игра, совместимая с майном (клон/сторонний клиент). Код и механики — наши; авторские права
  у Mojang/Microsoft на код, текстуры, звуки, модели, логотипы, название «Minecraft» (товарный знак).
- В APK — только своё: свой набор текстур/звуков (стиль ванильный, рисунок свой). Без «Minecraft» в названии и описании.
- Оригинальные ресурсы — только по выбору игрока: «взять из установленного Minecraft PE» или любой ресурс-пак (не раздаём).
- Свободные ресурсы с лицензией (CC0 / CC BY-SA с указанием авторов) — можно взять как основу (проверять лицензию каждого).
- Иконка NOVA сейчас из текстуры травы Mojang — для магазина перерисовать.
