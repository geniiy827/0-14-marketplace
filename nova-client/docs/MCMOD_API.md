# McMod Script — функции и события

_Сгенерировано из `mcmod/api/*.tsv` (tools/gen_mcmod.py). Статус: работает / в работе / нет._

## (общие)

| функция | возвращает | статус | описание |
|---|---|---|---|
| `print(value:any)` | - | работает | Пишет значение в чат (для отладки) и в лог |
| `str(value:any)` | str | работает | Превращает значение в строку |
| `num(value:any)` | num | работает | Превращает строку в число (null, если не число) |
| `int(value:num)` | num | работает | Отбрасывает дробную часть |
| `len(value:any)` | num | работает | Длина строки, списка или таблицы |
| `type(value:any)` | str | работает | Тип значения: number string bool list map fn null |
| `random(a:any=null, b:any=null)` | num | работает | random() дробное 0..1; random(a, b) целое от a до b включительно (если a и b целые); random(n) целое 0..n |

## События

| событие | поля e | e.cancel() | статус | описание |
|---|---|---|---|---|
| `on world.join(e)` | - | - | в работе | Игрок вошёл в мир |
| `on world.leave(e)` | - | - | в работе | Игрок вышел из мира |
| `on tick(e)` | - | - | в работе | 20 раз в секунду, пока игрок в мире. Удобнее: every 20 ticks { } |
| `on chat(e)` | $text | да | в работе | Игрок отправил сообщение или команду (e.text). e.cancel() — не отправлять |
